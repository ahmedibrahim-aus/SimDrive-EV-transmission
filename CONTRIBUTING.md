# Contributing

Please open an issue before you start on a change, so that we can agree on it
first. Before you report a problem, run `check_dependencies` in `instructor/`.
In the report, include its output, your MATLAB release and operating system,
and the steps that reproduce the problem.

Issues are public. Do not post answer-key values, worked student solutions or
the archive password in an issue; email them to the corresponding author.
Contributions are accepted under the repository licenses, BSD-3-Clause for code
and CC BY-SA 4.0 for course materials.
