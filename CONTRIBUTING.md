# Contributing

Issues and pull requests are welcome.

The project needs MATLAB R2025b or newer and is tested on R2025b and R2026b on
Windows.

Please keep changes scoped and reproducible:

1. Run `check_dependencies` in MATLAB before reporting runtime problems.
2. Do not commit generated artifacts such as exported `.mat` files, PNG plots, or autogenerated Simulink build outputs (except the hand-out in `student_package/`, which `buildStudentPackage` regenerates).
3. Preserve MATLAB R2025b+ release compatibility unless there is a documented reason to raise the minimum version.
4. Keep instructor-facing outputs traceable to the equations documented in `MathematicalModels.md`.
5. Update `README.md`, `Contents.m`, and `CITATION.cff` when a release changes repository metadata.

## Student hand-out

`instructor/buildStudentPackage.m` builds the student hand-out from a complete
export and needs nothing beyond the MATLAB products the project already requires.
