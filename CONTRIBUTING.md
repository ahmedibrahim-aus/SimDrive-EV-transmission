# Contributing

Contributors are asked to open an issue before starting a change, so that the
change can be agreed in advance. Before reporting a problem, run
`check_dependencies` in `instructor/`. The report should include its output, the
MATLAB release, the operating system and the steps that reproduce the problem.

Issues are public. Answer-key values, worked student solutions and the archive
password must not be posted in an issue and should instead be sent by email to
the corresponding author.

Contributions are accepted under the repository licenses, BSD-3-Clause for code
and CC BY-SA 4.0 for course materials.
